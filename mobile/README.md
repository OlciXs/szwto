# Odkrywca Zabytków

Aplikacja korzysta ze stałego backendu:

```text
https://szwto.onrender.com
```

Adres jest skonfigurowany w aplikacji i nie trzeba go podawać podczas
logowania.

## Uruchomienie aplikacji na Androidzie

```powershell
flutter pub get
flutter devices
flutter run -d <id_telefonu>
```

## Budowanie aplikacji webowej

```powershell
flutter build web --release
```
